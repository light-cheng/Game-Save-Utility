# Game Save Utility v0.1.3

> **Language / 语言**: English | [简体中文发布说明 (Chinese Release Notes)](https://github.com/light-cheng/Game-Save-Utility/blob/main/docs/releases/v0.1.3.md)

## Release Type

Performance Optimization / Architectural Deduplication / CI/CD Automation / Compliance & Localization Enhancements

This release focuses on dramatically improving background save change detection performance (eliminating UI main thread SHA-256 full directory hashing overhead), deduplicating preset and Steam path logic, introducing an official open-source license and package metadata, establishing automated GitHub Actions release CI/CD, and strengthening bilingual error localization parity.

## Highlights & Key Changes

- **Fingerprint-First Performance (Two-Tier Change Detection)**: Introduced a two-tier change detection mechanism (`QuickDirectoryFingerprint` + full SHA-256 hash). During periodic background save checks and auto-backup evaluation, the system first compares file count, total byte size, and latest modification timestamp (`mtime`). Full SHA-256 directory hashing is only triggered when fingerprint deviation is detected, completely eliminating UI stuttering, frame drops, and heavy disk I/O in the main thread.
- **Open-Source Compliance & Metadata**: Officially added the MIT License (`LICENSE`) to the repository and populated standard package fields in `Cargo.toml` (repository URL, readme, and license identifier).
- **CI/CD Automated Release Workflow**: Added an automated GitHub Actions release workflow (`.github/workflows/release.yml`) that runs code formatting checks (`cargo fmt`), test suites (`cargo test`), and Clippy linter on push to `v*` tags, then builds optimized Windows binaries and automatically drafts/publishes the GitHub Release.
- **Preset Rule Deduplication (Single Source of Truth)**: Refactored preset save paths and Steam library detection heuristics, eliminating duplicate rule maintenance across `presets.rs` and `steam.rs`. `presets.rs` is now the sole single source of truth for known game save path resolution.
- **Localized Error Handling & Parity**: Resolved error context leakage and fallback asymmetry between English and Simplified Chinese. Ensured all user-facing error messages and contexts route through localized mappers (`localize_error_context` and `localize_error_message`), preventing technical English errors from surfacing in the Chinese UI.
- **Naming Consistency & Repository Organization**: Standardized release asset naming conventions (`GameSaveUtility-v{version}-windows-x64.*`) and cleaned up repository root clutter by organizing screenshots into `docs/images/`.
- **Dynamic Windows PE Metadata**: Updated `build.rs` to dynamically parse the version directly from `Cargo.toml` at compile time, eliminating hardcoded version numbers across Windows resource files.

## Fixed Issues

- Fixed UI thread stutter and high disk I/O caused by unconditional full SHA-256 hashing during background auto-backup and save alteration checks.
- Fixed architectural redundancy and potential desynchronization between `presets.rs` and `steam.rs` save path discovery rules.
- Fixed untranslated technical English error strings leaking into the Chinese user interface in failure scenarios.
- Fixed missing formal open-source license file and incomplete Cargo package metadata fields.
- Fixed the release process relying on manual builds by establishing automated GitHub Actions CI/CD.

## Compatibility

- Backwards compatible with all existing backups created in earlier versions (content-addressable CAS object storage, ZIP archives, and directory copies are fully recognized and restorable).
- Application configuration file at `%LOCALAPPDATA%\GameSaveUtility\config.json` remains completely compatible.
- The utility continues as a portable, standalone Windows desktop application with zero external runtime dependencies.

## Upgrade Recommendations

Recommended for all users. Users with automatic backups enabled, save change detection active, or games with large save folders will experience significantly reduced CPU and disk I/O usage and a smoother UI experience.
